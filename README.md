AppHotelJuliah

Aplicativo de Reservas de Hotel

Projeto desenvolvido em .NET MAUI e C# como atividade do curso de Desenvolvimento de Sistemas da ETEC.

Funcionalidades

* Cadastro do nome do hóspede.
* Seleção da data de entrada.
* Definição da quantidade de hóspedes.
* Seleção do tipo de quarto: Standard, Luxo ou Suíte.
* Solicitação de reserva.
* Tela Sobre com informações do projeto.

Tecnologias utilizadas

* C#
* .NET MAUI
* XAML
* GitHub
